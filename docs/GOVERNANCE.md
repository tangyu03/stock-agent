# 阶段二优先级（用户复核后调整，2026-07-22）

## 执行顺序

### Step 0（最先执行，测量卫生前提）
**信号生成器重写** — 在回测层加信号调度器，保持 TimingEngine 不变
- 持仓跟踪：维护当前持仓状态（哪些股票已持仓、仓位、成本价、买入日期）
- 期望排序分配：买入信号按 entry_type 期望值排序（用 A6 已计算的期望）
- 预算约束：单股最大仓位 25 万、最大并发 4 只、T+1 约束
- 主动放弃：期望太低的买入信号不进入"跳过"统计，而是"主动放弃"（区别于资金不足被动跳过）
- 理由：在 88% 信号被跳过的状态下，任何规则修改的 A/B 对比都会被资金约束的随机性污染。先修生成器，后续每一项 P0 改动才有干净的度量

### P0（保留，日频引擎可验证）
- B1 五日线回归（派发日降级辅助，5日线之上分激情/谨慎两档）
- C1 破位止损改硬触发（跌破即执行，量能/投票只决定推送级别）
- D1 恐慌抄底触发点修正（关键点位破位+尾盘确认）
- F3 星期规则（周五收摊/周一抄底/AI不过周末）
- F6 情绪熔断（连续亏损/单日超阈停止交易）
- F9 北向数据替换（融资余额/ETF申赎/主力资金替代，2024-08起官方停披）

### 数据层先行（降级，需补分钟级/竞价数据后才能验证）
- F4 日内时段规则（"开盘1分钟不参与""尾盘15分钟异动"在日K+T+1开盘引擎里无法回测验证）
- F11 竞价数据（"竞价换手达标"同样需要分钟级/竞价数据支撑）
- 顺序：先补分钟级/竞价数据层，再谈规则实现。强行实现等于引入不可证伪的"推断参数"

### 专项关卡（贯穿阶段二全程）
**2024 段期望变化必报** — 每完成一项 P0 修改，除了跑全量三曲线，必须单独报告 2024 段（242 交易日）的期望变化
- 理由：2024 V型转折期 -0.90% 的负期望是五个缺陷里唯一没有被任何 P0 项直接命中的（B1/D1 只能间接缓解）
- 它是策略追涨杀跌倾向的显影剂
- 它转正之日才是"五日线 + 尾盘确认"组合真正起效的证据

### 实盘影子记录（与阶段二并行）
7 月科创高位剧震期实盘观察窗口，每改完一项 P0，同步做影子记录
- 历史回测告诉你规则对不对
- 实盘影子告诉你执行跟不跟得上
